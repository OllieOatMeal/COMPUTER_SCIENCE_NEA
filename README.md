This is my game that I made for my AQA A Level Computer Science Non Examined Assessment. The game is a single player blackjack game with a fully working GUI. It uses several A Level techniques to achieve this.

I will be creating a game in Tkinter, the user interface made through Python. I have chosen Python because of the way that it allows for integration of object-oriented programming, along with the ease of debugging in Python with the extensive support libraries. This game will be where the user will use their mouse to decide what actions they wish to take in the game. The game will be BlackJack where the user either plays against the dealer or chooses to play against bots. There will be menus that will direct the user and ensure that they know what they are doing. Once the player finishes the round the data will be added to their profile and displayed on the leaderboard. This will be implemented using SQL where all the information about the user is stored in relational databases. Text files will be used to store different rules and instructions that the user can read and will be displayed on screen.
